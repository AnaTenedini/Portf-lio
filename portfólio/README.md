💧 Projeto escolar: Monitoramento do consumo de água
 
Este projeto foi desenvolvido com o objetivo de ajudar as pessoas a acompanhar melhor o consumo de água e perceber possíveis desperdícios.
 
A proposta surgiu a partir da falta de informações em tempo real sobre o consumo de água nas residências. Com um sistema de monitoramento, seria possível visualizar os dados com mais facilidade e identificar situações que poderiam gerar desperdício ou gastos desnecessários.
